# Каталог utils

Здесь размещаются вспомогательные классы и функции, которые используются во всём backend-проекте CabrioRide.

## Основные файлы

- **ResponseHelper.php** — формирование стандартных ответов API (success, error, структура ответа)
- **AuthHelper.php** — функции для проверки авторизации, ролей, токенов
- **ValidationHelper.php** — функции для валидации входных данных
- **Database.php** — подключение к базе данных через параметры из .env (Singleton)

---

## Database.php — подключение к БД

Класс Database инкапсулирует подключение к MySQL через PDO. Все параметры берутся из файла .env в корне проекта.

**Пример использования:**

```php
$pdo = Database::getInstance();
$stmt = $pdo->prepare("SELECT * FROM users WHERE id = ?");
$stmt->execute([$id]);
$user = $stmt->fetch();
```

- Класс реализует паттерн Singleton: подключение создаётся один раз на весь запрос.
- Не храните параметры подключения в коде — только в .env!

---

> Все утилиты должны быть максимально простыми, переиспользуемыми и не содержать бизнес-логики.
