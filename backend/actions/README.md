# actions/ — Бизнес-логика (уровни 1-4)

Классы для сложных действий и бизнес-логики с уровнями абстракции (L1-L4).

## 📁 Структура папок

```
actions/
├── level1/              # Базовые операции (префикс: _)
├── level2/              # Бизнес-операции (префикс: __)
├── level3/              # Сложные сценарии (префикс: ___)
├── level4/              # Комплексные сценарии (префикс: ____)
├── helpers/             # Вспомогательные функции для переиспользования
│   ├── README.md        # Документация Helpers
│   ├── FileHelper.php   # Работа с файлами
│   ├── ValidationHelper.php # Дополнительная валидация
│   └── IntegrationHelper.php # Внешние интеграции
├── ACTIONS_INTERACTION.md # Стандарты взаимодействия Actions
└── README.md            # Этот файл
```

## 🎯 Уровни абстракции

### **L1 (Базовые операции)** — простые комбинации
- Комбинация 2-3 операций L0 (моделей)
- Простая бизнес-логика
- Базовая валидация данных
- Обработка файлов (фото, документы)
- **Префикс: 1 подчёркивание (_)**

### **L2 (Бизнес-операции)** — проверки и правила
- Используют Actions L1
- Проверки прав доступа
- Бизнес-правила
- Валидация бизнес-логики
- **Префикс: 2 подчёркивания (__)**

### **L3 (Сложные сценарии)** — транзакции и интеграции
- Используют Actions L2
- Транзакции БД
- Интеграции с внешними API
- Множественные операции
- **Префикс: 3 подчёркивания (___)**

### **L4 (Комплексные сценарии)** — полные пользовательские сценарии
- Используют Actions L3
- Полные пользовательские сценарии
- Оркестрация множественных операций
- **Префикс: 4 подчёркивания (____)**

## 🔄 Обмен данными

Actions общаются между собой **именованными массивами**:

```php
// Входные данные
$data = [
    'user_id' => 123,
    'car_data' => ['brand' => 'BMW', 'model' => 'Z4'],
    'context' => ['source' => 'telegram_bot']
];

// Результат
return [
    'success' => true,
    'data' => ['id' => 456, 'brand' => 'BMW'],
    'meta' => ['execution_time' => 0.05]
];
```
